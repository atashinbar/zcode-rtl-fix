# پچ نمایش راست‌به‌چپ (RTL) برای ZCode Desktop

مشکل: متن‌های فارسی در پنجره چت ZCode با جهت چپ‌به‌راست (LTR) نمایش داده می‌شوند؛
در نتیجه ترتیب کلمات و علائم به‌هم می‌ریزد و متن از سمت چپ چیده می‌شود.

## معماری واقعی (با بازرسی زنده DOM تأیید شده)

چت داخل همان صفحه محلی `out/renderer/index.html` رندر می‌شود — بدون iframe،
بدون webview و بدون shadow DOM. پیام‌های دستیار داخل `div.group/assistant-row`
با عناصر معنایی `p` / `li` / `h1..h6` رندر می‌شوند و پیام‌های کاربر داخل
`div.group/user-row`. (نکته: اتریبیوت `data-trajectory-message-role` در کد باندل هست
اما هرگز در DOM ظاهر نمی‌شود؛ سلکتورهایی که به آن گره خورده‌اند هیچ چیزی را
مچ نمی‌کنند.)

## راه‌حل

`install.sh` سه چیز تزریق می‌کند (همه با مارکر، idempotent):

1. **`rtl-fix.css`** → یک `<style>` در `index.html`:
   `p, li, h1..h6, blockquote, td, th, ... { unicode-bidi: plaintext !important; text-align: start; }`
   یعنی هر پاراگراف جهتش را از اولین حرف قوی خودش می‌گیرد (فارسی → راست‌به‌چپ و
   تراز از راست؛ انگلیسی/کد → چپ‌به‌راست دست‌نخورده). بلوک‌های کد (`pre`/`code`)
   تغییر نمی‌کنند. فیلدهای ورودی هم خط‌به‌خط هوشمند می‌شوند.
2. **`rtl-fix-page.js`** → یک `<script>` در `index.html`: روی div/span های
   `white-space: pre-wrap` (حباب پیام کاربر) `dir="auto"` می‌گذارد و با
   MutationObserver پیام‌های استریم‌شده جدید را هم همان لحظه پوشش می‌دهد.
3. **`rtl-fix-preload.js`** → به `codingPlanWebview.cjs` اضافه می‌شود؛ تور اطمینان
   برای اگر روزی نمای چت در webview رندر شود.

نکته مهم: `text-align: start` بدون `!important` است تا به استایل‌های عمدی اپ
(مثل متن وسط‌چین) غلبه نکند؛ `unicode-bidi` با `!important` است چون ترتیب حروف
نباید توسط استایل‌های اپ شکسته شود.

## نصب

```bash
cd ~/ZCodeProject/zcode-rtl-patch
./install.sh
```

سپس ZCode را کامل ببندید (**Cmd+Q**) و دوباره باز کنید.

پیش‌نیاز: Node.js (به‌خاطر `npx @electron/asar`).

## حذف

```bash
./uninstall.sh
```

نسخه اصلی `app.asar` در `~/.zcode/rtl-patch/app.asar.backup` نگهداری می‌شود و
برگردانده می‌شود.

## نکته‌های مهم

- **بعد از هر آپدیت ZCode** کل `ZCode.app` (شامل `app.asar`) جایگزین می‌شود و پچ پاک
  می‌شود؛ نه اپ خراب می‌شود و نه آپدیت به‌خاطر پچ شکست می‌خورد. فقط کافی است
  `install.sh` را دوباره اجرا کنید و بعد ZCode را ری‌استارت کنید.
- **محافظ دانگرید:** `install.sh` اگر ببیند asar فعلی تمیز است (یعنی ZCode تازه
  آپدیت شده) بکاپ را از همان نسخه تمیزِ جدید بازسازی می‌کند؛ `uninstall.sh` هم اگر
  ببیند اپ آپدیت شده و پچی ندارد، کاری نمی‌کند (دانگرید اصراری: `--force`).
- امضای کد اپ بعد از تغییر `app.asar` نامعتبر می‌شود؛ برای اپ نصب‌شده روی همین
  سیستم و برای آپدیت‌های بعدی مشکلی ایجاد نمی‌کند (آپدیتر امضای بسته جدید را چک
  می‌کند، نه اپ فعلی را).
- اگر روزی ZCode بعد از پچ بالا نیامد: `./uninstall.sh` را در ترمینال بزنید.

## تکنیک دیباگ (برای مرجع)

اگر نسخه‌های بعدی ZCode ساختار را عوض کردند و پچ بی‌اثر شد:

```bash
open -a ZCode --args --remote-debugging-port=9222
```

سپس با CDP (مثلاً `curl http://127.0.0.1:9222/json/list` و WebSocket) می‌توان DOM
زنده را بازرسی کرد، راه‌حل را همان‌جا تست کرد و بعد در پچ پیاده کرد. ری‌استارت
معمولی، پورت دیباگ را برمی‌دارد.

## اجرای خودکار بعد از آپدیت (اختیاری)

```bash
./enable-auto-reapply.sh    # فعال
./disable-auto-reapply.sh   # غیرفعال
```

یک LaunchAgent می‌سازد که `app.asar` را زیر نظر دارد و هر ۱۰ دقیقه هم چک می‌کند؛
اگر ZCode آپدیت شده و پچ پاک شده باشد، دوباره نصبش می‌کند (اگر پچ موجود باشد هیچ
کاری نمی‌کند). گزارش در `~/.zcode/rtl-patch/auto-reapply.log`. بعد از آپدیت+پچِ
خودکار، برای اثر کردن پچ یک ری‌استارت ZCode لازم است.

## فیلد تایپ چت (مهم)

فیلد تایپ چت یک ادیتور Lexical (`contenteditable`) است، نه textarea — و جهت متن را
**خودِ ادیتور مدیریت می‌کند**. پچ عمداً به آن (و به textarea/inputها و محتوای داخل
ادیتور) هیچ دست نمی‌زند؛ دخالت CSS/JS باعث رفتار غلط جهت در ادیتور می‌شد. اگر روزی
جهت فیلد تایپ به‌هم ریخت، اول مطمئن شوید نسخه‌ی به‌روز پچ نصب است (نسخه‌های قدیمیِ
پچ به ادیتور دست می‌زدند).

## ساخت پکیج برای اشتراک‌گذاری با دیگران

```bash
./make-dist.sh
```

در پوشه `dist/` سه چیز ساخته می‌شود:

- **`ZCode-RTL-Fix-Installer.command`** — نصاب تک‌فایلی؛ فقط همین را به دیگران بدهید.
  دابل‌کلیک کنند (اگر macOS گیت‌کیپر مانع شد: راست‌کلیک → Open). فایل‌ها را در
  `~/zcode-rtl-patch` می‌ریزد و نصب را شروع می‌کند.
- **`ZCode-RTL-Fix.zip`** — کل پوشه پچ برای کسانی که کل مجموعه می‌خواهند.
- **`ZCode-RTL-Fix/`** — پوشه خام.

پیش‌نیاز برای گیرنده‌ها: Node.js نصب باشد و ZCode در `/Applications/ZCode.app`.
محدوده: فقط macOS.
